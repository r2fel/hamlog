# Как запускать на макбуке

## Обычный способ — двойной щелчок

В папке лежит файл **«Запустить QSO Log.command»**.
Щёлкните по нему дважды — откроется окно терминала, приложение запустится,
и браузер откроется сам.

Пока это окно открыто — приложение работает. Чтобы остановить: закройте
окно или нажмите `Control + C`.

### Если Mac откажется открывать файл

При первом запуске macOS может сказать, что файл из неизвестного
источника. Тогда:

1. Щёлкните по файлу **правой кнопкой** (или Control + щелчок).
2. Выберите **«Открыть»**.
3. В появившемся окне снова нажмите **«Открыть»**.

Это нужно сделать один раз, дальше будет запускаться обычным двойным
щелчком.

---

## Что делает запускалка сама

- Проверяет, установлен ли Node.js, и подсказывает, где взять, если нет.
- При первом запуске сама устанавливает нужные компоненты.
- Логин QRZ.RU / QRZ.com спрашивается прямо в приложении при первом
  запуске (можно пропустить и вести журнал офлайн) — редактировать `.env`
  вручную не нужно.
- Если прошлый запуск остался висеть и занял порт — сама его закрывает
  (та самая ошибка `EADDRINUSE`, с которой вы сталкивались).
- Открывает браузер на нужном адресе.

---

## Способ через терминал

Если привычнее руками:

```
cd путь/к/папке/qso-log-qrz
npm start
```

Остановить — `Control + C`.

---

## Когда терминал не нужен совсем

После размещения приложения в интернете (см. файл
`РАЗМЕЩЕНИЕ-В-ИНТЕРНЕТЕ.md`) макбук будет не нужен вообще: приложение
работает на сервере круглосуточно, а вы просто открываете иконку на
айфоне. Терминал понадобится только если захотите что-то поменять и
проверить локально.
