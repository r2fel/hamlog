# Как разместить приложение в интернете

После этого журнал будет работать на телефоне из любого места — ноутбук
включать не нужно.

Мы используем Render.com: у него есть бесплатный тариф, которого для этой
задачи достаточно.

---

## Шаг 1. Загрузите проект на GitHub

GitHub — это хранилище файлов, откуда Render будет брать ваше приложение.

1. Зайдите на **github.com** и зарегистрируйтесь (бесплатно), если аккаунта нет.
2. Нажмите зелёную кнопку **New** (создать репозиторий).
3. Имя репозитория: `qso-log`
4. Выберите **Private** (приватный) — чтобы файлы не были видны посторонним.
5. Нажмите **Create repository**.
6. На открывшейся странице нажмите ссылку **uploading an existing file**.
7. Перетащите в окно браузера **содержимое** папки `qso-log-qrz`:
   файлы `server.js`, `package.json`, `README.md`, `render.yaml`,
   `.env.example`, `.gitignore` и папку `public`.

   ВАЖНО: файл `.env` со своими паролями НЕ загружайте. Пароли мы введём
   отдельно, в настройках Render — так они останутся закрытыми.

8. Внизу нажмите **Commit changes**.

---

## Шаг 2. Подключите Render

1. Зайдите на **render.com**, нажмите **Get Started** и войдите через GitHub.
2. Разрешите Render доступ к вашему репозиторию `qso-log`.
3. Нажмите **New +** → **Web Service**.
4. В списке выберите репозиторий `qso-log`, нажмите **Connect**.
5. Проверьте настройки (обычно подставляются сами):
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**

---

## Шаг 3. Введите пароли

На той же странице найдите раздел **Environment Variables** и добавьте
по одной штуке (кнопка **Add Environment Variable**):

| Имя переменной   | Значение                                    |
|------------------|---------------------------------------------|
| `QRZRU_USERNAME` | ваш API-логин с qrz.ru                      |
| `QRZRU_PASSWORD` | ваш API-пароль с qrz.ru                     |
| `QRZCOM_USERNAME`| ваш логин на qrz.com                        |
| `QRZCOM_PASSWORD`| ваш пароль на qrz.com                       |
| `ACCESS_KEY`     | код доступа, который придумаете сами        |

Про `ACCESS_KEY`: это защита от посторонних. Придумайте что-нибудь вроде
`R3EED-moy-log-2026`. Приложение спросит этот код один раз при первом
поиске позывного и запомнит его. Без кода чужой человек, случайно попавший
на ваш адрес, не сможет тратить ваш лимит запросов к QRZ.

Затем нажмите **Create Web Service** и подождите несколько минут.

---

## Шаг 4. Установите на телефон

Когда Render закончит, вверху страницы появится адрес вида
`https://qso-log-xxxx.onrender.com`

1. Откройте этот адрес на айфоне в **Safari**.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран Домой»** → **Добавить**.

Готово. Теперь иконка работает из любого места, где есть интернет.

---

## Что нужно знать

**Первый запуск бывает медленным.** На бесплатном тарифе Render «усыпляет»
приложение после получаса без использования. Следующее открытие займёт
около минуты — это нормально, дальше работает быстро.

**Журнал хранится на телефоне**, а не на сервере. Это значит: записи никуда
не денутся, если сервер уснёт или вы смените хостинг. Но если очистить
данные Safari — журнал пропадёт. Экспорт записей в файл стоит добавить
следующим шагом.

**Работает и без интернета.** Приложение откроется и позволит вести записи;
не будет работать только автоматический поиск позывных.

**Про лимиты QRZ.RU.** У них правило: сервис только для личного
использования, не чаще одного запроса в 3 секунды. Приложение это
соблюдает автоматически. Код доступа нужен именно для того, чтобы
посторонние не нарушили эти правила от вашего имени.

---

## Как работает вход

При первом открытии приложение спросит код доступа (тот, что вы задали
в `ACCESS_KEY`). Вводится один раз и запоминается на этом устройстве —
больше спрашивать не будет.

Кнопка **⚙** справа вверху позволяет ввести код заново, если понадобится.

Если запускаете приложение только у себя на компьютере и `ACCESS_KEY`
не задан, никакого входа не будет — поиск работает сразу.
